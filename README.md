# 🛒 E-Commerce Sales Analysis

An end-to-end **E-Commerce Sales Analysis project** built using Python, MySQL, Excel, and Power BI.

The project focuses on transforming raw Kaggle e-commerce data into meaningful business insights by performing data cleaning, exploratory data analysis, SQL analysis, and interactive dashboard development.

---

## 📊 Project Overview

E-commerce businesses generate large amounts of sales data, but raw data alone does not provide clear answers to important business questions.

This project analyzes e-commerce sales data to understand:

- 💰 Overall revenue and sales performance
- 📦 Order volume and order status
- 🌎 Revenue distribution across states
- 🛍️ Revenue contribution by product category
- 💳 Customer payment preferences
- 📅 Revenue trends over signup dates
- 🔄 Refund amounts
- 📈 Average Order Value (AOV)

The final result is an interactive **Power BI E-Commerce Dashboard** designed to provide a high-level view of business performance.

---

## 🎯 Objectives

The main objectives of this project were:

1. Clean and prepare raw e-commerce data for analysis.
2. Perform exploratory data analysis using Python.
3. Use SQL to query and analyze business data.
4. Identify important sales and customer trends.
5. Calculate important business KPIs.
6. Build an interactive Power BI dashboard.
7. Present insights in a simple and business-friendly format.
